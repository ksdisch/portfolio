## Method

- **Lens:** a hiring manager opens the repo cold — does the README match repo reality, can a
  stranger run it, do carded stats trace to committed result artifacts.
- **Scope:** each repo audited at a pinned `origin/main` snapshot (SHA noted per section), via
  read-only worktrees — local checkout state was out of scope. `reclaim-eval` and
  `jacobian-lens` excluded (paper authors' reference packages, per the GAPS ledger).
- **Process:** one auditor+brainstormer agent per repo (9), then one adversarial verifier per
  repo (8) instructed to *refute* every critical/should-fix finding against the actual repo and
  to kill any idea violating the charter. 37 serious findings went to verification: **35
  CONFIRMED, 2 DOWNGRADED, 0 refuted**; 0 of 48 ideas died on charter grounds. Three findings
  (the two CI-runs-zero-tests claims, the lossy-wall denominator, and the blind-cite state flip)
  were additionally re-checked by hand in the main session. Nice-to-have findings are reported
  unverified; `trajectory-otel`'s light section is descriptive throughout.
- **Completeness:** nothing found was omitted — every finding, improvement, and idea from the
  sweep appears in the per-project sections below (there is no separate appendix because zero
  findings were refuted). Severity grades and the top-10 are the filter, not omission.
- **Charter guardrails on ideas:** judge-free deterministic scoring, pre-registered gates,
  Wilson/Newcombe CIs, hobby budget (< $5, cheap/tiny models). Closed repos stay closed —
  science extensions are tagged `seed-hunt-candidate` (banked, the way mute-map's declined S1/S2
  became J-lens backlog idea #13), never proposed as reopenings.
- **Suppressed as in-flight (not findings):** hush-gauge's open PR #10 (M2/G3 — carded
  status-only by design until it merges) and, at audit launch, blind-cite's PR #8. The latter
  then merged mid-audit — see the state change below.
